# Security policy

The emulator is a development tool. It serves made-up data and accepts any API key unless started with `--api-key`, so run it on localhost or a network you trust and don't expose it to the internet.

## Reporting a vulnerability

Please report security issues privately through [GitHub's private vulnerability reporting](https://github.com/dubsector/meraki-api-emulator/security/advisories/new) instead of opening a public issue. Include steps to reproduce and the commit you tested.

Fixes go to the latest commit on `main`.
